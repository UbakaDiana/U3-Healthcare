# U3 Healthcare 

## Project Overview

This project focuses on analyzing hospital discharge data to understand patient discharge patterns, length of hospital stay, and how discharges vary across different patient demographics and months.

The dashboard was developed using Power BI to transform healthcare data into meaningful insights that can support hospital performance monitoring and data-driven decision-making.

## Objectives

The main objectives of this project were to:

* Monitor total hospital discharges and average daily discharge rates.
* Analyze discharge patterns by gender and day of the week.
* Understand the distribution of discharges across different age groups.
* Evaluate the average length of stay (ALOS) by age group and gender.
* Track monthly discharge trends and identify periods of higher or lower discharge activity.

## Dashboard Features

The dashboard includes the following key performance indicators (KPIs):

* Total Discharges: 12,488
* Average Daily Discharge Rate: 17
* Average Length of Stay (ALOS): 7 days

## Conclusion

This project demonstrates how healthcare data can be transformed into an interactive dashboard that makes discharge patterns and hospital utilization easier to understand.

The dashboard provides a consolidated view of key healthcare indicators and allows users to explore trends by region, time, age group, and gender.

## Disclaimer

This dashboard was developed for analytical and portfolio purposes. The findings reflect the dataset used and should not be interpreted as evidence of clinical outcomes or hospital performance without further investigation.
